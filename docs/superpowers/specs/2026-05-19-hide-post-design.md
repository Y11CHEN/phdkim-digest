# 帖子隐藏功能 设计文档

## 目标

允许用户在浏览时隐藏不感兴趣的帖子，隐藏状态持久保存在本地浏览器，无需修改服务端数据。

## 数据模型

复用收藏功能的 localStorage 模式：

- Key：`phdkim_hidden`
- Value：JSON 数组，存被隐藏帖子的 id 列表
- 隐藏是不可恢复操作（无管理入口）

## 交互流程

每个帖子右侧在 `☆` 收藏按钮旁新增 `✕` 隐藏按钮。

**点击 `✕`：** 原地显示内联确认区，`✕` 按钮本身隐藏：

```
👍 120 | 2025.03.10   [☆]  隐藏？[是] [否]
```

**点击「是」：**
1. 将该帖 id 写入 `phdkim_hidden`
2. 若该帖在收藏中，同时从 `phdkim_favs` 移除
3. 帖子立即从页面消失（所有视图）

**点击「否」：** 隐藏确认区，恢复 `✕` 按钮。

## 渲染逻辑

`applyView()` 在展示每个 `.post` 前先判断其 id 是否在 hidden set 里，若在则 `display:none`，对目录、全文、收藏三个视图均生效。

## 改动范围

| 文件 | 改动内容 |
|------|---------|
| `scraper/html_gen.py` | 新增 `✕` 按钮和内联确认 HTML；新增 `getHidden`、`saveHidden`、`startDelete`、`cancelDelete`、`doHide` JS 函数；更新 `applyView` 过滤隐藏帖；新增 `.del-btn`、`.del-confirm` CSS |

`posts.json`、`scrape.py` 及其他脚本无需改动。

## 不在范围内

- 不提供"查看已隐藏"或"恢复隐藏"入口
- 不同步到服务端
- 不改变收藏、目录/全文切换等现有功能行为
